## 📌 Overview

**VidyaSetu** is a prototype **AI-enabled Scholarship and Fellowship Management System** developed for the **Smart India Hackathon 2026**.

The platform is designed around the requirements of the **Ministry of Tribal Affairs (MoTA)** and aims to simplify the end-to-end management of scholarship and fellowship schemes for Scheduled Tribe students.

It brings applicants, documents, eligibility rules, verification, scrutiny, communication, and administrative monitoring into a single digital workflow.

### Core Concept

**One Applicant Profile → Reusable Documents → Scheme-Specific Rules → AI-Assisted Verification → Human Oversight**

## ❗ Problem

Scholarship and fellowship administration can involve several manual and repetitive activities, including:

- Repeated submission of the same documents.
- Manual document verification and scrutiny.
- Incomplete or incorrect applications.
- Repeated communication regarding deficiencies.
- Difficulty tracking application status.
- Different eligibility rules for different schemes.
- Limited real-time monitoring for administrators.
- Manual effort in reporting and application management.

These challenges can increase processing time and administrative workload.

---

## 💡 Proposed Solution

VidyaSetu provides a centralized platform for managing scholarship and fellowship applications through configurable digital workflows.

The system combines:

- Centralized applicant profiles.
- Reusable document management.
- Scheme-specific eligibility rules.
- AI-assisted document processing.
- Automated eligibility checks.
- Deficiency detection and resubmission.
- Application status tracking.
- Administrative dashboards.
- Analytics and reporting.
- Human-in-the-loop verification.

- Document resubmission.

---

## 📄 Reusable Document Repository

Applicants can maintain a centralized collection of their documents.

Instead of uploading the same document repeatedly, previously submitted documents can be reused wherever applicable.

### Supported Document Examples

- Caste Certificate
- Income Certificate
- Mark Sheets
- Degree / Admission Documents
- Identity Documents
- Research / Academic Documents
- Scheme-specific documents

---

## 🤖 AI-Assisted Document Verification

The AI/OCR layer can assist with:

- Document type identification.
- Information extraction.
- Document completeness checking.
- Missing information detection.
- Data inconsistency detection.
- Flagging applications requiring manual review.

> **AI assists authorized officials; final verification and decision-making remain under human control.**
